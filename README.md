# ResiveSMS

**ResiveSMS** — это Android-приложение для автоматической фильтрации и пересылки SMS сообщений.  
Приложение позволяет пользователю задавать **паттерны текста** для поиска в входящих SMS и выбирать, куда пересылать сообщения: на телефон или в **Telegram**.  

Приложение разработано с учётом следующих особенностей:

- Поддержка Android 5.0 (Lollipop) и выше  
- Настройка фильтров, номера телефона и Telegram через удобный интерфейс  
- Использование Kotlin и AndroidX для стабильной и быстрой работы  
- Минимальное использование ресурсов и быстрая сборка APK  

---

## Особенности

1. **Паттерны**: позволяют фильтровать SMS по содержимому.  
2. **Номер для пересылки**: любое валидное международное или локальное число.  
3. **Пересылка через Telegram**: сообщения можно отправлять напрямую в чат или группу.  
4. **Кнопки выбора способа пересылки**: SMS или Telegram (`RadioButton`).  
5. **Хранилище настроек**: данные сохраняются локально и не отправляются в интернет без вашего разрешения.  
6. **Поддержка нескольких паттернов**: можно задавать несколько фильтров через разделитель `|`.

## Интеграция с Telegram

Чтобы использовать пересылку сообщений в Telegram:

1. Создайте **бота** (@ParResiveSMS_bot) через [@BotFather](https://t.me/BotFather) в Telegram:
   - `/newbot` → задайте имя и username бота
   - Получите **TOKEN бота**, который будет использоваться для отправки сообщений.
2. Добавьте бота в **группу или канал**, где хотите принимать сообщения:
   - Отправьте любое сообщение в группу, чтобы активировать чат.
3. Узнайте **chat_id**:
   - Для групп: chat_id (https://api.telegram.org/bot@botToken@/getUpdates) будет отрицательным числом (`-1234567890`)  
   - Для личных чатов: используйте ваш личный chat_id (можно получить через API или специальные боты для теста)
4. В приложении **введите**:
   - Telegram Bot Token  
   - Chat ID  
5. Выберите переключателем **"Пересылка через Telegram"**.  

> Примечание: для работы Telegram интернет на устройстве должен быть включен.

## Формат заполнения

### Паттерны

- Разделяются символом `|`  
- Каждый паттерн проверяется на **вхождение в текст SMS**  
- Пример:  
```

Карта *7857|OTP|Подтверждение

```
- Объяснение:
  - `Карта *7857` — совпадение с текстом, содержащим номер карты  
  - `OTP` — совпадение с одноразовым паролем  
  - `Подтверждение` — совпадение с любым сообщением, содержащим слово «Подтверждение»

### Номер телефона

- Поддерживается **международный формат** и **локальный формат**  
- Примеры:
  - Международный: `+79621234567`  
  - Локальный (Россия): `89261234567`

## Установка

1. Сборка APK через Android Studio:
```

Build → Build Bundle(s) / APK(s) → Build APK(s)

```
2. Установка на устройство Android 5.0+  
3. Настройка паттернов, номера и/или Telegram токена и chat_id в приложении  
4. Выбор способа пересылки через кнопки (SMS / Telegram)  

---

## Безопасность

- Для SMS пересылки требуется **только разрешения SMS**  
- Для Telegram требуется **разрешение на интернет**  
- Все настройки хранятся локально  
- Пересылка сообщений в Telegram происходит **только на указанный вами бот/чат**  

---

## Примечание

- Сообщения пересылаются **автоматически**, если содержат заданные паттерны  
- Telegram пересылка работает только при наличии интернета на устройстве  
- Telegram Bot должен быть активирован в чате (бот добавлен и чат_id правильный)
